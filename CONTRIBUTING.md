# Contributing to Last Purpose

Last Purpose is currently a closed-source project developed in a private repository.

Contributions are accepted only by invitation or prior agreement with ElKeyaru. Before starting work, open an issue or contact the repository owner to agree on scope and ownership terms.

## Development requirements

- Target Project Zomboid Build 42 stable.
- Treat Singleplayer as the supported mode unless a task explicitly expands that scope.
- Do not include Project Zomboid files or assets from other mods.
- Do not include saves, logs, personal paths, credentials, or local backups.
- Preserve the `LastPurposeB42` mod ID.
- Keep both `mod.info` files synchronized.
- Use additive, non-destructive ModData migrations.
- Test with a Burglar character and inspect `console.txt` after changes.
- Create a backup before significant changes.

By submitting a contribution, you confirm that it is your original work or that you have permission to submit it. Acceptance of a contribution does not make the repository open source or change the project license.
